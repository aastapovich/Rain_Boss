# Инструкция по добавлению анимаций брызг для разных типов капель

## Текущее состояние
Сейчас все капли используют одну анимацию **"Rain_splash"**. Код уже настроен для поддержки разных анимаций.

## Как добавить свои анимации

### 1. Откройте сцену Game.tscn в редакторе Godot

### 2. Найдите ноду **Animated_shwaps**
Путь: `Game → Elements → Animated_shwaps`

### 3. В инспекторе выберите **Sprite Frames**

### 4. Добавьте новые анимации:

#### Для обычных капель (вода):
- **Имя анимации:** `Rain_splash_water`
- Добавьте свои спрайты брызг для обычной воды

#### Для золотых капель:
- **Имя анимации:** `Rain_splash_gold`
- Добавьте свои спрайты брызг для золота (например, с золотыми блёстками)

#### Для живительных капель:
- **Имя анимации:** `Rain_splash_live`
- Добавьте свои спрайты брызг для живительных капель (например, с зелёным свечением)

### 5. Настройте параметры каждой анимации:
- **Loop:** false (анимация не зацикливается)
- **Speed:** 20.0 (или на свой вкус)

## Типы капель в коде

| Тип капли | Код передаёт | Ищет анимацию |
|-----------|-------------|---------------|
| Обычная вода | `"water"` | `Rain_splash_water` |
| Золотая | `"gold"` | `Rain_splash_gold` |
| Живительная | `"live"` | `Rain_splash_live` |

## Fallback механизм

Если анимация для конкретного типа не найдена, система автоматически использует стандартную **"Rain_splash"**.

Это значит, что игра будет работать, даже если вы ещё не добавили все анимации!

## Пример

```
Капля "gold" попадает на игрока
↓
Код ищет анимацию "Rain_splash_gold"
↓
Если найдена → проигрывает её
Если НЕ найдена → проигрывает "Rain_splash" (текущая)
```
